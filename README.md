#  Landing Gear Mechanism – Project WOO (Wings Over OPAIC)

A hands-on embedded systems project that simulates the extension and retraction of an aircraft landing gear system using a **Raspberry Pi Pico**, sensors, and actuators. This project is part of my final-year Studio 5 and Studio 6 capstone series at OPAIC (Otago Polytechnic Auckland International Campus).

---

##  Project Description

Landing gear systems are critical to aircraft safety, especially during take-off and landing. This project simulates the physical behavior of landing gear using embedded hardware and software, offering a practical way to explore real-time control systems, microcontrollers, and avionics concepts.

The project is divided into two phases:
- **Studio 5** – Focus on basic control logic and sensor integration.
- **Studio 6** – Expansion into cockpit interface, safety interlocks, and potentially IEC 61499 modeling.

---

##  Goals

### Studio 5:
- Simulate landing gear extension/retraction using servos or linear actuators.
- Control hardware using Raspberry Pi Pico.
- Detect gear position using sensors.
- Create a physical prototype on a breadboard.
- Record and visualize output states.

### Studio 6 (Planned):
- Build a cockpit-style control panel.
- Add interlocks and safety indicators.
- Explore safety-critical design principles.
- (Optional) Apply IEC 61499 Function Blocks for modular system design.
